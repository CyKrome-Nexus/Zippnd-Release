Every platform, one protocol

The share button your devices never agreed on.

Every Zippnd app runs the same Rust transfer engine, so a Mac and an Android phone speak exactly the same language — no cloud in the middle, no cable, no account.

◎Nearby, instantly

Devices on your network appear on the radar by themselves. Pick one, drop files on the window, done.

⚿Encrypted end to end

Every transfer runs over a Noise XX session, and both sides prove their device key before a byte moves.

?Always asked first

The receiver sees who is sending and how much, can untick files, and decides the order they arrive in.

↻Picks up where it stopped

Wi-Fi dropped mid-file? What arrived is kept, Zippnd reconnects, and Retry carries on from the last byte.

✓Verified on arrival

Files stream in 64 KB frames, are checked with BLAKE3, and only get their name once they are whole.

⇄From Finder & Explorer

“Send with Zippnd” in the Services menu and the Send to menu, or drag straight onto the window.

◐Your call on visibility

Everyone nearby, only Contacts you have shared with, or Off — gone from other screens within seconds.

∞Your own ecosystem

Pair your devices once with a six-digit code. On Ecosystem they send with no prompt and share a clipboard.

∅No account to share

Install and send. A CyKrome account is only for Pro, Ecosystem and pairing your own devices.

Peer to peer

Straight from one device to the other.

Your files never touch a server. Zippnd finds devices on the local network, opens an encrypted session directly between the two, and moves the bytes as fast as the network allows.

  • ✓Discovery over mDNS. Every device advertises _zippnd._tcp on the local network.
  • ✓Mutually authenticated. Noise XX, so both ends know exactly whose device they are talking to.
  • ✓Live progress on both sides. File n of N, speed, time left, and a speed graph in Details.
  • ✓Stays reachable. Close the window and Zippnd keeps listening from the tray, if you want it to.

Get it

Download Zippnd

Run one command in your terminal to install Zippnd on macOS or Linux, or download the Windows installer or the Android app directly from the latest release.

Zippnd for iPhone isn’t available yet. Open this page on your computer or an Android phone to install it there.

bash
curl -fsSL https://github.com/CyKrome-Nexus/Zippnd-Release/releases/latest/download/install-mac.sh | bash
✓ Installs into /Applications ✓ Auto-removes Gatekeeper quarantine ✓ Apple Silicon & Intel native

This path is preferred until Apple Developer ID signing is configured, because it also clears the macOS quarantine attribute after install. Allow Local Network access when asked — that is how Zippnd finds devices nearby.

bash
curl -fsSL https://github.com/CyKrome-Nexus/Zippnd-Release/releases/latest/download/install-linux.sh | bash
✓ Installs AppImage to ~/.local/share ✓ Desktop menu integration ✓ Adds zippnd command

This path is preferred because it installs the AppImage, menu entry, and terminal command together, and the AppImage updates itself.
